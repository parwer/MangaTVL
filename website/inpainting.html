Stage 04 · Inpainting

ลบข้อความเดิม โดยไม่กินเส้นขอบฟอง

ใช้ border-uniformity safe-fill — หด polygon เข้าทีละขั้นแล้ววัดความสม่ำเสมอของ pixel ที่ขอบ เพื่อหา mask ที่อยู่ "ในเนื้อขาวของฟอง" พอดี ไม่ทาบเส้นขอบดำ

image + TranslationResult[] → inpaint() → cleaned image

ปัญหา: polygon ของ YOLO-seg มัก "ล้น" เลยขอบฟอง

🔴

Inpaint กินขอบ / smear — polygon จาก segmentation มักล้ำออกนอกเส้นฟองนิด ๆ ถ้าทาขาวตาม polygon ตรง ๆ จะลบเส้นขอบดำของฟองไปด้วย เกิดรอยเลอะ

วิธีแก้: หด polygon + วัด std ของขอบ

แนวคิด (adapt จาก PanelCleaner): พื้นที่ภายในฟองเป็นสีขาวสม่ำเสมอ ส่วนเส้นขอบเป็นสีดำ ดังนั้นถ้าเราหด (erode) polygon เข้าไปเรื่อย ๆ แล้ววัด ส่วนเบี่ยงเบนมาตรฐาน (std) ของ pixel ตามแนวขอบ mask — ขอบที่ std ต่ำ = อยู่ในเนื้อขาวล้วน (ปลอดภัย) ส่วนขอบที่ std สูง = ยังพาดเส้นดำอยู่ ลองลากแถบด้านล่าง:

Adaptive erode · ลากเพื่อหด polygon เข้า
erode steps: 0 border std: 48
std ต่ำ = ปลอดภัยเส้น = threshold 25

เลือก mask ที่ปลอดภัยที่สุด

_pick_safe_polygon_mask หด polygon เข้าทีละ step (ขนาด step ปรับตามเส้นทแยงของฟอง) วัด std ที่ขอบทุกขั้น แล้วเลือกตัว std ต่ำสุด ถ้า std ต่ำสุดยังเกิน max_std=25 → คืน None (skip ฟองนี้ ตกไปวิธี box-based แทน):

def inpaint(self, image, inputs):
    inputs = self.parse_inputs(inputs)
    image, demoted = self._safe_fill_polygons(image, inputs)  # ฟองที่ปลอดภัย → ทาขาว
    if not demoted:
        return image
    mask = self._masking(image, demoted)                  # ที่เหลือ → box-based
    return self._inpaint(image, mask, inputs=demoted)

สองเส้นทาง: safe-fill ก่อน, box-based เป็น fallback

เส้นทางหลัก

Polygon safe-fill

ฟองที่หา mask ปลอดภัยได้ (std < 25) → ทาขาวทับ ภายในฟองตรง ๆ ได้ผลคมและเร็ว ไม่ต้องเดา texture

fallback

Box-based inpaint

ฟองที่ polygon ยังไม่ปลอดภัย (เช่นพื้นหลังมีลาย) ถูก demote ไปทำ mask แบบกล่อง แล้ว inpaint ด้วย OpenCV telea หรือ Simple-LaMa

✅

ผลลัพธ์: ฟองส่วนใหญ่ใช้ safe-fill (สะอาด คม) และเฉพาะ edge case ที่ตกไป box-based — แก้ปัญหา polygon overshoot โดยไม่เสียคุณภาพกับฟองปกติ
