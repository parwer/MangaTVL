Stage 01 · Detection

ตรวจจับฟองคำพูด เป็น polygon ไม่ใช่แค่กรอบ

สเตจแรกใช้ YOLO segmentation หาตำแหน่งฟองคำพูดในหน้ามังงะ และคืน รูปทรง polygon ของแต่ละฟอง — ข้อมูลที่จะถูกพาไปใช้ในทุกสเตจถัดไป

PIL.Image (หน้ามังงะ) → YoloDetection.detect() → DetectionResult[ ]

แนวคิด: ทำไม polygon ดีกว่า box

ฟองคำพูดมักวางใกล้กัน ถ้าตรวจจับเป็น กรอบสี่เหลี่ยม ล้วน กรอบของฟองหนึ่งจะกินพื้นที่ (และข้อความ) ของฟองข้าง ๆ ทันทีที่ฟองไม่ได้เป็นทรงสี่เหลี่ยม ลองสลับมุมมองด้านล่างเพื่อเห็นความต่าง:

Box vs Polygon · ฟองสองใบที่อยู่ใกล้กัน
กดปุ่มด้านบน — สังเกตว่ากรอบสี่เหลี่ยมของฟอง B (สีแดง) ทับเข้าไปในฟอง A ส่วน polygon (สีเขียว) แนบรูปฟองจริง จึงไม่กินกัน

Backend: YoloDetection

backend หลัก/default ปัจจุบัน ใช้ ultralytics.YOLO รองรับทั้งไฟล์ .pt และ .onnx และทำงานได้ทั้ง task detect และ segment:

result = self.model(image, conf=self.conf, iou=self.iou, device=self.device)[0]
boxes    = result.boxes.xyxy.cpu().numpy()        # [x1,y1,x2,y2]
cls_ids  = result.boxes.cls.cpu().numpy()
polygons = result.masks.xy if result.masks is not None else None  # polygon!
return self.build_results(boxes, cls_ids, polygons)
⚠️

โมเดลต้องเป็นรุ่น -seg (เช่น yolo26n-seg.pt) เท่านั้น ถ้าใช้รุ่น detect-only โมเดลจะไม่มี seg head ทำให้ result.masks เป็น None และไม่ได้ polygon — ทุกประโยชน์ของ v2 จะหายไป

NMS — กันกล่องซ้อนซ้ำ

DetectorBase กำหนด contract .detect(image) → list[DetectionResult] ร่วมของทุก backend พร้อม helper build_results ที่แปลง output แบบ ultralytics (xyxy + class ids + polygons จาก result.masks.xy) เป็น schema และตัดกล่องที่ซ้อนทับกันมากด้วย Non-Max Suppression ตาม IoU

โมเดล & Dataset

Base model

  • yolo26n-seg.pt (ต้องเป็น -seg)
  • default weight: assets/models/best_diplom.pt (resolve แบบ package-relative)
  • weight (*.pt/*.onnx) ถูก gitignore — ต้องจัดหาแยก

Dataset (Roboflow)

  • diplom-uhct7/manga-6puie v4
  • nc: 1, names: ['bubble'] — class เดียว
  • train 1,304 / valid 189 / test 103 ภาพ (polygon labels)
  • มี negative samples (~15%) ช่วยลด false positive
🔴

ข้อจำกัดที่รู้: dataset มี class เดียว (bubble) → detect ฟองคำพูดแม่น แต่ ไม่รู้จัก SFX / ตัวอักษรวาดมือ / free_text ดูแนวทางแก้ใน ปัญหา & อนาคต

Output schema

class DetectionResult(BaseModel):
    bbox: list[int]                              # [x1, y1, x2, y2]
    segmentation: list[list[int]] | None = None  # polygon [[x,y], ...]
    form_type: str                               # "bubble" / "free_text"

หมายเหตุ: ONNXDetection (box-only) ยังอยู่ในโค้ดเป็น legacy option แต่ เลิกใช้เป็น default แล้ว
