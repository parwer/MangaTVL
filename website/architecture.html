System · สถาปัตยกรรม

โครงสร้างข้อมูล, API และการตั้งค่า

วิธีที่สเตจทั้งห้าต่อกันด้วย Pydantic schema, การเปิดเป็น FastAPI service (ทั้งแบบ batch และ streaming) และการปรับ config ต่อ request

1 · Data contracts (Pydantic)

ทุกสเตจสื่อสารด้วย model ใน schemas/interface.py โดย DetectionResult (พร้อม polygon) ถูก ฝังต่อกันไปเรื่อย ๆ จนถึงสเตจสุดท้าย:

การไหลของ schema · แต่ละชั้นห่อชั้นก่อนหน้า
เพราะ TranslationResult ห่อ OCRResult ที่ห่อ DetectionResult → สเตจ inpaint และ render จึงเข้าถึง polygon ของฟองจริง ได้แม้อยู่ปลายทาง

2 · FastAPI service (main.py)

รับ list ของ image URL ที่ client เก็บจาก DOM (เช่น browser extension ที่อ่านหน้า reader) แล้วรัน pipeline ทุกภาพ คืน base64 ที่ index ตรงกับ request (null สำหรับภาพที่ล้มเหลว)

Endpointหน้าที่
POST /translate/แปลทั้ง batch แล้วคืน {"images": [base64 | null, ...]} ทีเดียว (index-aligned)
POST /translate/stream/body เดียวกัน แต่ stream เป็น NDJSON หนึ่งบรรทัดต่อภาพ ทันทีที่ภาพนั้นเสร็จ (completion order)
GET /fonts/คืน catalogue ฟอนต์ที่ใช้ได้ { "fonts": [{key, label, scripts}] }

Streaming (NDJSON) — ทยอยส่งทีละภาพ

แทนที่จะรอทั้ง batch เสร็จก่อน run_batch_stream ใช้ asyncio.as_completed yield (index, image) ตามลำดับที่เสร็จ — client สลับภาพในหน้าได้ทันที:

{"index": 2, "image": "data:image/jpeg;base64,..."}
{"index": 0, "image": null}                 # ภาพนี้ล้มเหลว
{"index": 1, "image": "data:image/jpeg;base64,..."}

มี header X-Accel-Buffering: no + Cache-Control: no-cache กัน proxy/CDN buffer

3 · Per-request overrides

provider/model/ภาษา/ฟอนต์/ขนาด ฯลฯ เลือกได้ ต่อ request (omit = ใช้ default ของ server + env key) translator และ OCR engine ถูก cache ต่อ (provider, key) และต่อภาษา จึงไม่โหลดโมเดลใหม่ทุกครั้ง:

{
  "images": ["https://cdn.example.com/p1.jpg", ...],
  "process_image": false,        # ส่งรูปเป็น visual context ให้ LLM
  "provider": "openrouter",     # openrouter | gemini | groq
  "api_key": "sk-...",
  "model": "google/gemini-2.5-flash",
  "from_lang": "english",       # เลือก OCR engine ด้วย (japanese → manga-ocr)
  "to_lang": "thai",
  "font": "itim",
  "text_scale": 1.2,            # 0.5 – 2.0
  "upscale": 2,                 # 1 – 4
  "upscaler": "lanczos"         # lanczos | realesrgan
}

4 · Client: tempomunkey userscript

เพราะหน้าที่ "หารูปมังงะในหน้าจริง" ทำได้ดีที่สุดฝั่ง client ที่เห็น DOM ที่ render แล้ว จึงมี Tampermonkey userscript ให้ผู้ใช้เลือกหน้าที่จะแปลบน reader โดยตรง:

  • วาง checkbox overlay บนรูปใหญ่ทุกใบ + floating bar (Select all / Visual context / Translate / Interrupt / Revert / Rescan / Settings)
  • ส่งผ่าน GM_xmlhttpRequest (ข้าม CORS/mixed-content https→http localhost)
  • อ่าน NDJSON stream แบบ incremental → swap ภาพในหน้าทีละใบ พร้อม badge ✓/✕
  • Settings: provider / model / source & target language / font / text size / upscale / api_key (persist ใน GM storage)

5 · Configuration & deploy

Environment (.env)

OPENROUTER_API_KEY=...   # หรือ GROQ / GOOGLE
DEVICE=cpu               # cpu | cuda
PROVIDER=openrouter
MODEL=google/gemini-3-flash-preview
CONCURRENT_REQUESTS=4

หมายเหตุ: provider gemini อ่าน GOOGLE_API_KEY (ไม่ใช่ GEMINI_API_KEY)

Docker

# CPU
docker compose up --build

# GPU (CUDA)
docker build -f Dockerfile.gpu \
  -t mangatvl-gpu .
docker run --gpus all \
  -e DEVICE=cuda -p 8000:8000 \
  --env-file .env mangatvl-gpu

model weight + ฟอนต์ถูก bake เข้า image; ส่งแค่ API key ตอน runtime

6 · โครงสร้างโปรเจกต์

MangaTVL/
├── main.py                  # FastAPI app
├── pipeline.py              # Pipeline orchestrator (5 สเตจ)
├── manga_translator/
│   ├── detection/           # YoloDetection, ONNXDetection (legacy)
│   ├── ocr/                 # EasyOCR / manga-ocr / PaddleOCR + clean_poly
│   ├── translators/         # OpenRouter / Gemini / Groq
│   ├── inpainting/          # OpenCV / Simple-LaMa
│   ├── rendering/           # TextRenderer, fonts, tokenize, upscale
│   ├── schemas/interface.py # Detection/OCR/Translation Result
│   ├── utils/               # geometry (inscribed_rect), lang map
│   └── assets/              # fonts, models, languages.json
├── tests/                   # pytest suite (pure logic)
├── CHANGELOG.md  ·  report.md   # ภาษาไทย
└── tempomunkey.user.js      # Tampermonkey client
🧪

Tests: pytest suite ครอบเฉพาะ pure logic (geometry, การ parse response ของ LLM, text_no mapping, การ build detector output, clean_poly, การเลือก inpaint mask) — ไม่ต้องใช้ model weight หรือ API key
