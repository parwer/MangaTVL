Stage 05 · Rendering

วาดคำแปลให้พอดีฟอง — ตัดคำตามภาษา

หาพื้นที่วาดที่เป็น สี่เหลี่ยมใหญ่ที่สุดที่อยู่ในรูปฟอง (Largest Inscribed Rectangle) แล้วปรับขนาดฟอนต์อัตโนมัติให้ข้อความพอดี ไม่ล้นนอกเส้น

cleaned image + TranslationResult[] → render() → ภาพผลลัพธ์

หัวใจ: Largest Inscribed Rectangle (LIR)

ฟองมักเป็นทรงรี ถ้าวาดข้อความเต็ม bounding box ตัวอักษรจะล้นออกนอกเส้นโค้ง ระบบจึงหา สี่เหลี่ยมที่ใหญ่ที่สุดที่ยังอยู่ในรูป polygon ทั้งหมด เป็นกรอบวาด ลองสลับชั้นด้านล่าง:

polygon → LIR → fit text
ลำดับการเลือกพื้นที่วาด (priority): polygon LIR → det.bbox inset → OCR-union fallback — LIR ทำให้ข้อความอยู่ในเส้นฟองเสมอ

หา LIR ยังไง

inscribed_rect (ใน utils/common.py) แปลง polygon เป็น raster แล้ว erode → หาสี่เหลี่ยมใหญ่สุดด้วยอัลกอริทึม "largest rectangle in histogram" ความเร็ว O(H×W):

rasterize(polygon) → erode → largest_rectangle_in_histogram(mask)  # O(H×W)

ปรับขนาดฟอนต์ + กันล้น

  • auto font-size — binary search หาขนาดฟอนต์ที่ใหญ่สุดที่ยังพอดี LIR
  • stroke scaling — ความหนาเส้นขอบตัวอักษรปรับตามฟอนต์ (max(1, fs//12)) และนับ stroke เข้าใน fit check ด้วย
  • fallback ไม่ล้น — ถ้าย่อจนต่ำกว่า min font แล้วยังไม่พอ → truncate + ใส่ "…"

ตัดบรรทัดตามภาษาปลายทาง

การขึ้นบรรทัดถูกขับด้วย field wrap ใน languages.json เลือก 3 โหมดตาม to_lang:

โหมดภาษาวิธีตัด
pythainlpไทยตัดคำด้วย newmm ไม่ตัดกลางคำ (import แบบ lazy)
charญี่ปุ่น / จีนตัดได้ทุกตัวอักษร (CJK ขึ้นบรรทัดแบบนี้อยู่แล้ว)
spaceอังกฤษ / เกาหลี / defaultตัดที่ช่องว่าง คำอยู่ครบ

คุณภาพการแสดงผล: ใหญ่ขึ้น + คมขึ้น + ขยายได้

text_scale

LIR ของฟองรีมักเล็กเกินไป → text_scale (default 1.2) ขยายพื้นที่ฟิตจาก LIR ออกไปหา bbox ตามสัดส่วน (cap ที่ขอบฟอง) ให้ข้อความเต็มฟองขึ้น

supersample

วาดข้อความบน overlay ที่ scale 2× แล้ว downscale LANCZOS → ขอบ glyph คมขึ้นที่ขนาดเดิม โดยไม่แตะอาร์ตเวิร์ก

upscale

ขยายภาพ final ได้ (1–4×): lanczos (เร็ว) หรือ realesrgan (AI deblur อาร์ตเวิร์ก, fallback เป็น lanczos ถ้าไม่พร้อม)

ฟอนต์

มีฟอนต์มังงะ/คอมิกหลายแบบ (OFL/Apache) ครอบ 4 สคริปต์ เลือกได้ต่อ request ผ่าน font key — ถ้าไม่ระบุจะใช้ default ตาม to_lang เพื่อให้ CJK/เกาหลีได้ glyph ที่ถูก ไม่เป็นกล่อง tofu:

ไทย: TH Sarabun · Itim · Mali · Sriracha · Charm Latin: Bangers · Comic Neue · Permanent Marker · Patrick Hand ญี่ปุ่น: Yusei Magic จีน: Zhi Mang Xing เกาหลี: Nanum Pen

รายการฟอนต์อยู่ที่ GET /fonts/ — เพิ่มฟอนต์ใหม่แค่วาง .ttf + เพิ่ม entry ใน fonts.json
