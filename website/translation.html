Stage 03 · Translation

แปลทั้งหน้าทีเดียวด้วย LLM แล้ว map กลับด้วย text_no

ข้อความทุกฟองในหน้าถูกรวมเป็น JSON เดียวส่งให้ LLM แปลพร้อมกัน (ได้ context ทั้งหน้า) แล้วผลลัพธ์ถูกจับคู่กลับฟองเดิมด้วยหมายเลข ไม่ใช่ลำดับ

OCRResult[] (+ รูป context) → translator.translate() → TranslationResult[ ]

ทำไมแปลทั้งหน้าทีเดียว

ถ้าแปลทีละฟองแยกกัน LLM จะไม่เห็น context ของบทสนทนา — คำสรรพนาม น้ำเสียง และการต่อประโยคจะเพี้ยน การส่งทั้งหน้าไปก้อนเดียวให้โมเดล "อ่านบทสนทนาทั้งฉาก" แล้วแปลให้สอดคล้องกัน อีกทั้งประหยัด API call

การ map ด้วย text_no (ไม่ใช่ positional zip) 
by_no = {int(r["text_no"]): r["translated_text"] for r in parse_response(resp)}
translated = by_no.get(i, ocr_item.text)   # ไม่มี → fallback ข้อความเดิม
ทำไมต้อง text_no: LLM อาจคืนผลสลับลำดับหรือตกหล่นบางรายการ ถ้าใช้ positional zip คำแปลจะลงผิดฟอง การ map ด้วย text_no + fallback เป็นข้อความเดิม ทำให้ผิดฟองไม่เกิด และฟองที่แปลไม่ได้ยังคงข้อความต้นฉบับไว้

ส่งรูปเป็น multimodal part — ไม่ใช่ base64 ในข้อความ

เมื่อ process_image=true หน้าจะถูกย่อแล้วส่งให้ LLM เป็น visual context ช่วยให้แปลตรงอารมณ์ในภาพ จุดสำคัญคือ ส่งเป็น image part จริง ไม่ใช่ base64 ฝังใน text:

โครงสร้าง translator

ทุก provider เลือกด้วย string provider และสืบทอดจาก base เดียว — มี retry/backoff + semaphore จุดเดียว:

providerคลาสหมายเหตุ
openrouterAsyncOpenRouterTranslatorsubclass ว่างของ OpenAICompatibleTranslator (dedup โค้ด)
groqAsyncGroqTranslator
geminiAsyncGeminiTranslatorส่งรูปเป็น Part.from_bytes (google-genai)
  • AsyncTranslatorBase — สร้าง system prompt, throttle ด้วย asyncio.Semaphore(CONCURRENT_REQUESTS), มี _call_with_retry รวม rate-limit + backoff
  • คาดหวัง LLM คืน JSON array ของ {"text_no", "translated_text"} — parse โดย parse_response
🛡️

ไม่กลืน exception เงียบ ๆ ในจุดสำคัญ: ทุก fallback (แปลไม่ได้, parse ไม่ออก, ฟองหาย) จะกลับไปใช้ ข้อความต้นฉบับต่อฟอง แทนการทิ้งทั้งหน้า → หน้าจะไม่เคยกลายเป็นว่างเปล่า

System prompt

prompt สั่งให้โมเดลทำสองงาน: (1) sort ข้อความตามลำดับการอ่านมังงะ (ขวา→ซ้าย) (2) recontextualize เป็นภาษาปลายทางโดยรักษาอารมณ์/น้ำเสียงตัวละคร แล้วคืน JSON อย่างเดียว มี guidelines เช่น emotional fidelity, character voice, การใช้ภาษาพูด/คำหยาบให้เข้ากับโทน

  {"text_no": 0, "translated_text": "เวรเอ๊ย! ไอ้บ้า!"},
  {"text_no": 1, "translated_text": "ชิบหาย! เกิดอะไรขึ้นเนี่ย?"}
]
