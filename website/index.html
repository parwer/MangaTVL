MangaTVL เป็นบริการ FastAPI ที่รับภาพหน้ามังงะ/คอมมิค แล้ว ตรวจจับฟองคำพูด → อ่านข้อความ → แปลด้วย LLM → ลบข้อความเดิม → วาดคำแปลกลับลงภาพ ผ่าน pipeline 5 สเตจที่สลับเปลี่ยนชิ้นส่วนได้ทั้งหมด

🎯 YOLO-seg detection 🔤 EasyOCR / manga-ocr 🌐 OpenRouter · Gemini · Groq 🩹 Polygon-aware inpaint ✍️ Pillow + pythainlp ⚡ FastAPI streaming

ที่มาที่ไป

ทำไมต้องมีโปรเจกต์นี้

มังงะ/คอมมิคจำนวนมากมีเฉพาะต้นฉบับภาษาอังกฤษ การแปลด้วยมือต้องทำซ้ำ ๆ หลายขั้น — กวาดหาฟองคำพูด, พิมพ์ข้อความ, แปล, ลบของเดิม, แล้ววาดตัวอักษรใหม่ให้พอดีฟอง MangaTVL ยุบงานทั้งหมดนี้ให้เป็นท่อประมวลผลเดียวที่รับ "ภาพเข้า → ภาพแปลออก" และเปิดเป็น API ให้ client (เช่น userscript บนหน้าเว็บอ่านมังงะ) เรียกใช้แบบ batch ได้ — คุณภาพของแต่ละสเตจถูกวัดผลจริงบนหน้ามังงะ (ดู 📊 Evaluation)

v1 — จุดเริ่ม

ONNX box-only detection

รุ่นแรกตรวจจับฟองเป็น กรอบสี่เหลี่ยม ล้วน ทำให้ตอน crop ไป OCR กรอบมักกินข้อความของฟองข้าง ๆ → OCR ปนข้ามฟอง, คำแปลลงผิดฟอง, และ inpaint ลบเลยขอบ

v2 — ปัจจุบัน

YOLO-seg + polygon ทุกสเตจ

ย้ายมาใช้ YOLO segmentation ที่ให้ polygon ของฟองจริง แล้วพา polygon นั้นไหลผ่านทุกสเตจ — ใช้ clean OCR, safe-fill inpaint, และหาพื้นที่วาด (LIR) ตามรูปฟองจริง คือหัวใจที่แก้ปัญหาตั้งต้นของ v1

💡

แนวคิดหลัก: "รูปทรงของฟอง" (polygon) คือข้อมูลที่มีค่าที่สุด ถ้ารู้ขอบเขตฟองแม่น ๆ ตั้งแต่สเตจแรก ทุกสเตจถัดไปก็ทำงานสะอาดขึ้นทันที — นี่คือเหตุผลที่ทั้งระบบถูกออกแบบรอบ ๆ polygon

หัวใจ orchestrator

ทั้ง pipeline ถูกร้อยใน _run_on_image ตัวเดียว — อ่านง่ายและเห็นลำดับชัด:

async def _run_on_image(self, image, process_image=False):
    detection_result = self.det_model.detect(image)        # [1] ฟอง + polygon
    if not detection_result:
        return image                                  # ไม่มีอะไรให้แปล
    ocr_result = self._get_ocr(from_lang).get_ocr(image, detection_result)  # [2]
    context_image = self.resize_image(image) if process_image else None
    translation_result = await translator.translate(ocr_result, image=context_image) # [3]
    inpainted_image = self.inpainter.inpaint(image, translation_result)        # [4]
    return self.renderer.render(inpainted_image, translation_result)         # [5]

เจาะลึกแต่ละสเตจ

STAGE 01

Detection

YOLO segmentation หาฟองเป็น polygon — รวมถึง dataset, NMS และความต่างจาก box-only

 STAGE 02

OCR

crop ต่อฟอง + clean_poly ทาขาวนอก polygon เพื่อกัน OCR ข้ามฟอง

 STAGE 03

Translation

แปลทั้งหน้าทีเดียวเป็น JSON, map ด้วย text_no, ส่งรูปเป็น multimodal part

 STAGE 04

Inpainting

border-uniformity safe-fill: erode polygon + วัด std เพื่อลบข้อความโดยไม่กินขอบ

 STAGE 05

Rendering

Largest Inscribed Rectangle + auto font-size + ตัดคำต่อภาษา + supersample

 SYSTEM

สถาปัตยกรรม & API

Pydantic schema, FastAPI endpoints, streaming, per-request config, userscript
