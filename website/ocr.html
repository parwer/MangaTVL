Stage 02 · OCR

อ่านข้อความทีละฟอง — ทาขาวนอก polygon ก่อนอ่าน

แทนที่จะ OCR ทั้งหน้าทีเดียว ระบบ crop ต่อฟอง แล้ว ทาขาวทุกอย่างนอก polygon (clean_poly) เพื่อให้ OCR เห็นเฉพาะข้อความในฟองนั้น

image + DetectionResult[] → get_ocr() → OCRResult[ ]

ปัญหา: ทำไมไม่ OCR ทั้งภาพรวด ๆ

🔴

OCR overlap ข้ามฟอง — ถ้า crop เป็นสี่เหลี่ยม กรอบจะกินข้อความฟองข้าง ๆ (ดูได้จาก Stage 1) ทำให้ข้อความสองฟองปนกัน เป็นโจทย์ตั้งต้นที่ v1 เจอ

ทางแก้คือใช้ polygon จากสเตจ Detection มา "ลบ noise นอกฟอง" ก่อน — กดเดินทีละขั้นด้านล่าง:

crop → (ถ้าไม่ clean = พัง) → clean_poly → OCR

Code: clean_poly

เป็น method บน base OCREngine ใช้ร่วมทุก backend — ถ้าไม่มี polygon (detect-only) จะคืนภาพเดิม:

def clean_poly(self, cropped_image, poly, offset=(0,0), fill=(255,255,255)):
    if poly is None or len(poly) == 0:
        return cropped_image          # detect-only → คืนเดิม
    pts  = np.array(poly) - np.array(offset)   # shift polygon เข้ากรอบ crop
    mask = np.zeros(...); cv2.fillPoly(mask, [pts], 255)
    arr[mask == 0] = fill            # นอก polygon = ขาว
    return Image.fromarray(arr)

loop หลักของ OCR เหมือนกันทุก engine — crop → clean → อ่าน → map box กลับสู่พิกัดภาพเต็ม:

for det in detection_results:
    x1, y1, x2, y2 = det.bbox
    cropped = image.crop((x1, y1, x2, y2))
    cropped = self.clean_poly(cropped, det.segmentation, offset=(x1, y1))
    text, boxes = self.ocr(cropped)
    mapped = [[xmin+x1, ymin+y1, xmax+x1, ymax+y1] for ... in boxes]
    ocr_results.append(OCRResult(text=text, boxes=mapped, detection_result=det))
